# Pokémon Red, White & Blue (PETA Parody) – Offline Archive

This is an offline mirror of the browser game **Pokémon: Red, White & Blue — An Unofficial PETA Parody** originally published by PETA at:

https://games.peta.org/pokemon-red-white-blue-parody-game/

Released in 2013 as a sequel to *Pokémon Black & Blue*, this game features Pikachu, Miltank, Jigglypuff and others battling McDonald's-related characters.

## Why this archive exists
PETA has occasionally taken down or changed their interactive content. This repository preserves a playable copy of the HTML5 (Phaser) version of the game for historical / archival purposes.

## How to play
1. Clone or download this repository.
2. Serve the folder with any static web server:

```bash
# Python 3
python3 -m http.server 8000

# or Node.js
npx serve .
```

3. Open http://localhost:8000 in your browser.
